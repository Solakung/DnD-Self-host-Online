# DnD Table

เว็บสำหรับเล่น D&D กันเองในกลุ่ม เปิดคู่กับ Discord ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ ขึ้น GitHub Pages ได้ ใช้บนมือถือได้

- **ตัวละคร** — ฟอร์มสร้างตัวละคร คำนวณโมดิฟายเออร์ / โบนัสชำนาญ / HP / AC อัตโนมัติ กดทอยเช็ค เซฟ ทักษะ อาวุธได้จากชีทเลย มีปุ่มสุ่มสถานะ (4d6 ตัดต่ำสุด) แล้วจัดตามอาชีพให้ ส่งออก/นำเข้า JSON ได้
  - **เผ่า + ภูมิหลัง (กฎ 2024)** — เผ่า (Species) ตั้งความเร็วให้ ส่วนโบนัสสถานะมาจากภูมิหลัง 16 แบบ เลือก +2/+1 หรือ +1/+1/+1 ในสามค่าที่ภูมิหลังกำหนด และติ๊กทักษะชำนาญ 2 อย่างให้ (มีบอก เครื่องมือ และ Feat ของภูมิหลัง) เปลี่ยนภูมิหลังแล้วโบนัสเก่าถูกหักออกให้ ปุ่มสุ่ม/Standard บวกโบนัสให้ด้วย
  - **เกราะ/AC และทักษะอาชีพ (ตามตาราง PHB 2024)** — เลือกชุดเกราะ 12 แบบ + โล่ แล้วคำนวณ AC ให้ (เพดาน DEX ของเกราะกลาง, เกราะหนักไม่บวก DEX, Unarmored Defense ของ Barbarian/Monk) เตือนเมื่ออาชีพไม่ได้ฝึกเกราะนั้น, STR ไม่ถึง, หรือเสียเปรียบ Stealth ส่วนทักษะมีดาว ★ บอกว่าอาชีพเลือกได้อะไรกี่อย่าง พร้อมตัวนับ
  - **เวทมนตร์** — คำนวณ Spell Save DC / โบนัสโจมตีด้วยเวท / จำนวนเวทที่เตรียมได้ให้ตามอาชีพ เลเวล และค่าสถานะ ช่องเวทตามตาราง 5e (Full / Half caster / Warlock) แก้จำนวนเองได้ มีปุ่ม ✨ ร่าย หักช่องให้อัตโนมัติ (ใช้ช่องเลเวลต่ำสุดที่เหลือ) และทอยดาเมจถ้าใส่ไว้ พักยาวคืนช่องทั้งหมด
  - **กระเป๋า** — รายการของ (จำนวน / น้ำหนัก / กำลังใช้) เหรียญ PP GP EP SP CP คำนวณน้ำหนักรวมเทียบขีดจำกัด STR×15 (มีสถานะกฎเสริม encumbrance) และมูลค่าเงินรวมเป็น gp
- **กระดาน** — กริด 40×40 ซูมและเลื่อนได้ (เมาส์ + ทัช) วางโทเคน ลากแล้ว snap เข้าช่อง โชว์ระยะเป็น ft
  - เลือกโทเคนแล้วกด **สำเนา** เพื่อทำโทเคนซ้ำ ชื่อต่อเลขอัตโนมัติ (Goblin → Goblin 2 → Goblin 3)
  - กด **📏 วัดระยะ** แล้วลากบนกระดาน จะขึ้นระยะเป็น ft (ใช้ได้เฉพาะในเครื่องตัวเอง ไม่ซิงก์)
  - **🌫 หมอก (DM)** กด "ซ่อนทั้งหมด" แล้วลากถูบนกระดานเพื่อเปิดช่อง (เลือกพู่กัน 1/3/5 ช่องได้) ผู้เล่นเห็นหมอกทึบและไม่เห็นโทเคนที่อยู่ในหมอก DM เห็นเป็นหมอกโปร่ง
- **รูปบนกระดาน** — ทุกคนกด "🖼 รูป" เลือกรูปจากเครื่อง (แกลเลอรีมือถือได้) เพื่อแทรกแผนที่/ภาพประกอบ รูปแรกจะเต็มกริดเป็นแผนที่หลัก รูปต่อๆ ไปวางกลางจอ
  - แตะรูปเพื่อเลือก → ลากเพื่อย้าย → ลากวงกลมสีทองมุมขวาล่างเพื่อปรับขนาด → ปุ่ม "เต็มกริด" / ลบ
  - ผู้เล่นย้าย/ลบได้เฉพาะรูปที่ตัวเองใส่ DM จัดการได้ทุกรูป
  - รูปถูกย่อในเบราว์เซอร์ก่อน (ด้านยาวสุด ≤1600px, ไม่เกิน ~700KB) เก็บใน Realtime Database ไม่ต้องใช้ Firebase Storage
- **ลูกเต๋า** — แตะ d4–d100 ทอยทันที ตั้งจำนวน / โบนัสได้ ได้เปรียบ–เสียเปรียบ พิมพ์สูตรเองได้ (เช่น `8d6+4`) ประวัติการทอยซิงก์ทั้งห้อง
- **ห้องออนไลน์** — ใช้ Firebase Realtime Database + Anonymous Auth ถ้ายังไม่ตั้งค่า แอปจะทำงานแบบออฟไลน์

## ตั้งค่า Firebase (ทำครั้งเดียว)

1. [Firebase Console](https://console.firebase.google.com) → สร้างโปรเจกต์ (หรือใช้โปรเจกต์เดิมก็ได้)
2. **Build → Authentication → Sign-in method** → เปิด **Anonymous**
3. **Build → Realtime Database** → Create database
4. แท็บ **Rules** → คัดลอกเนื้อหาไฟล์ `database.rules.json` ไปวางทั้งหมด → Publish
   - ถ้าฐานข้อมูลนี้มีกฎของแอปอื่นอยู่แล้ว ให้เพิ่มเฉพาะก้อน `"rooms": { ... }` เข้าไปใน `"rules"` อย่าเขียนทับของเดิม
5. **Project settings → Your apps → Web (`</>`)** → คัดลอก config มาใส่ใน `firebase-config.js` (ต้องมี `databaseURL` ด้วย)

**สิทธิ์ตามกฎ:** ใครมีรหัสห้องก็อ่านห้องได้ · ผู้เล่นย้าย/แก้/ลบได้เฉพาะโทเคนและรูปของตัวเอง · DM (คนสร้างห้อง) จัดการได้ทุกอย่างและล้างทั้งกระดานได้ · ทุกคนทอยลูกเต๋าได้แต่แก้ประวัติเก่าไม่ได้ เหมาะกับกลุ่มเพื่อน ไม่ได้ออกแบบให้ทนคนประสงค์ร้าย

> หลังอัปเดตแอปเป็นเวอร์ชันที่มี "รูปบนกระดาน" หรือ "หมอก" ต้อง Publish กฎใหม่ด้วย ไม่งั้นการอัปโหลดรูปจะถูกปฏิเสธ (และปุ่ม "ล้างโทเคนทั้งหมด" ของ DM จะใช้ไม่ได้)

## ขึ้น GitHub Pages

1. สร้าง repo แล้วอัปโหลดไฟล์ทั้งหมด (`index.html`, `style.css`, `script.js`, `dice.js`, `firebase-config.js`)
2. **Settings → Pages** → Source: `Deploy from a branch` → `main` / `(root)`
3. เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
4. ถ้า Auth ฟ้อง `unauthorized-domain` → Firebase Console → Authentication → Settings → Authorized domains → เพิ่ม `<ชื่อผู้ใช้>.github.io`

> `apiKey` ของ Firebase เป็นค่าสาธารณะ ใส่ใน repo ได้ ความปลอดภัยอยู่ที่ Rules

## วิธีเล่น

1. DM กดปุ่มมุมขวาบน → ใส่ชื่อ → **สร้างห้อง** → **คัดลอกลิงก์ห้อง** ส่งเข้า Discord
2. ผู้เล่นเปิดลิงก์ ใส่ชื่อ → เข้าห้องอัตโนมัติ
3. ผู้เล่นสร้างตัวละครในแท็บ "ตัวละคร" → แท็บ "กระดาน" กด **ตัวฉัน** เพื่อวางโทเคน
4. ใครอยากเพิ่มแผนที่/ภาพ กด **🖼 รูป** ในแท็บกระดาน
5. ทอยจากชีทหรือแท็บลูกเต๋า ผลขึ้นให้ทั้งห้องเห็น

## ฟีเจอร์กระดาน (อัปเดตใหญ่)

- **แถบเครื่องมือ**: เลื่อน / ไม้บรรทัด / วาดเส้น / ข้อความ / แม่แบบเวท (วงกลม กรวย เส้น สี่เหลี่ยม) / ยางลบ / Ping / หมอก (DM)
- **โทเค็น**: แถบ HP, สถานะ (Condition), ซ่อน/ล็อก (DM), รูปโทเค็น, ทำซ้ำ, HP ผูกกับชีทตัวละครสองทาง
- **ลำดับตา (Initiative)**: ทอยทั้งหมด, ตาถัดไป, นับรอบ, ผู้เล่นเห็นตาปัจจุบัน
- **หลายฉาก (Scene)**: DM สร้าง/เปลี่ยนชื่อ/ลบฉาก และสลับฉากให้ทั้งห้อง
- **🏗 สร้างแมพ (DM)**: วาดห้อง (ห้องที่ติดกันรวมเป็นพื้นที่เดียว) / กำแพง / ประตู / ไอคอน 13 แบบ (โต๊ะ เตียง หีบ บันได ต้นไม้ ฯลฯ) แบบเวกเตอร์บนกริด ซิงก์ทั้งห้อง มี ↶ ↷ ย้อน/ทำซ้ำ (ใช้กับเครื่องมือวาด/เวทด้วย)
- **ไม้บรรทัดร่วม + Ping**: เพื่อนเห็นเส้นวัดและจุดที่ชี้แบบเรียลไทม์

## ระบบตาม PHB 2024 (เฉพาะชื่อและตัวเลข ไม่ได้คัดลอกเนื้อหา)

- เผ่า/ภูมิหลัง (ASI, ทักษะ, Origin Feat), ชุดเกราะ/AC, ทักษะตามอาชีพ, ช่องเวท, เหรียญ/น้ำหนักสัมภาระ
- **ตารางอาวุธ**: เลือกอาวุธ → โบนัสโจมตีและดาเมจคำนวณให้ (STR/DEX ตาม Finesse/ไกล, ชำนาญตามอาชีพ) พร้อมแสดง Weapon Mastery
- **Feat**: Origin/General/Fighting Style/Epic Boon; Origin Feat จากภูมิหลังขึ้นอัตโนมัติ; Archery, Dueling, Defense, Tough, Alert คำนวณให้

## อัปเดต Rules (สำคัญ)

เวอร์ชันนี้เพิ่ม path ใหม่ (ฉาก, วาด, ลำดับตา, ping, ไม้บรรทัด) → เปิด Firebase Console → Realtime Database → Rules → วางเนื้อหา `database.rules.json` → **Publish** ไม่งั้นฟีเจอร์ใหม่จะเขียนไม่ได้

## ข้อควรรู้

- ตัวตน DM ผูกกับเบราว์เซอร์ที่สร้างห้อง (Anonymous Auth) ถ้าล้างข้อมูลเบราว์เซอร์จะเสียสิทธิ์ DM ของห้องนั้น → สร้างห้องใหม่
- ตัวละครเก็บในเบราว์เซอร์ (localStorage) ควรกด **ส่งออก** สำรองไว้เป็นครั้งคราว
- รูปที่แทรกตอนออฟไลน์เก็บในเบราว์เซอร์ (เต็มได้เร็ว) ส่วนในห้องออนไลน์เก็บบน Firebase ห้องที่เลิกเล่นแล้วลบทิ้งได้ที่ Realtime Database → data → `rooms`
- ปุ่ม ได้เปรียบ/เสียเปรียบ ใช้กับการทอย d20 ครั้งถัดไปแล้วรีเซ็ตเป็นปกติเอง
- ถ้าจะลองบนเครื่อง ต้องเปิดผ่านเซิร์ฟเวอร์ (เช่น `npx serve` หรือ `python -m http.server`) เพราะใช้ ES modules เปิดไฟล์ตรงๆ จะไม่ทำงาน
